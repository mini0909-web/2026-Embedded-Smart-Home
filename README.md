# A-pit-Based Smart Home Automation System

TOPST 보드 2대와 노트북 웹 서버를 연결해 센서 기반 자동 제어와 원격 제어를 구현한 마이크로프로세서 프로젝트입니다.

조도·온습도·가연성 가스 센서로 주변 환경을 감지하고, 스마트 침대·커튼·조명을 제어합니다. 위험 조건이 감지되면 경고 장치와 웹 화면을 통해 사용자에게 알립니다.

## 프로젝트 목표

센서 입력부터 제어 판단, 액추에이터 동작, 통신, 웹 화면까지 연결되는 스마트홈 시스템을 구성하는 것을 목표로 했습니다.

수동 조작, 환경 기반 자동 제어, 시간 기반 루틴, 위험 상황 대응을 네 가지 모드로 구분했습니다.

## 하드웨어 및 통신 구성

| 구성 요소 | 용도 |
| --- | --- |
| TOPST 보드 2대 | 센서 데이터 수집 및 장치 제어 |
| 노트북 | Flask 웹 서버 실행 |
| 카메라 AI-G 보드 | 프로젝트 카메라 구성 |
| CDS 5파이 조도 센서 | 주변 밝기 감지 |
| 온습도 센서 | 온도 및 습도 측정 |
| 가연성 가스 센서 | 가스 감지 |
| 기어 모터 | 스마트 침대 및 커튼 구동 |
| 5파이 LED | 조명 및 경고 표시 |
| 액티브 부저 | 위험 상황 경고 |

- TOPST 보드 간 UART 통신
- TOPST 보드와 노트북 간 유선 네트워크 통신
- 센서 데이터 전달을 위한 HTTP/JSON 통신
- 웹 제어 명령 전달을 위한 시리얼 통신
- Flask 기반 웹 서버 및 GUI

## 시스템 동작 흐름

센서 감지 → 데이터 처리 → A-pit 제어 판단 → 동작 결정 → 액추에이터 구동 → 상태 통신 및 웹 표시

센서 데이터와 사용자 명령을 바탕으로 조명, 커튼, 침대를 제어하고 현재 상태를 웹 대시보드에 제공합니다.

## 주요 기능

### 스마트 침대·커튼·조명

기어 모터와 LED를 이용해 침대, 커튼, 조명을 제어합니다. 사용자 명령이나 선택한 모드에 따라 장치가 동작합니다.

### 센서 모니터링

조도, 온도, 습도, 가스 감지 상태를 웹에서 확인할 수 있습니다.

### 위험 상황 경고

설정한 위험 조건이 감지되면 위험 모드로 전환하고 LED·부저를 통해 경고합니다. 웹 화면에는 경고와 발생 원인을 표시합니다.

### 웹 기반 원격 제어

스마트폰과 태블릿 등에서 웹 서버에 접속해 장치를 조작하고 모드와 루틴을 관리할 수 있습니다.

## 네 가지 제어 모드

| 모드 | 동작 |
| --- | --- |
| 매뉴얼 모드 | 사용자가 웹에서 장치를 직접 원격 제어 |
| 스마트 제어 모드 | 센서 값에 따라 장치를 자동 제어 |
| 루틴 모드 | 사용자가 설정한 시간과 동작에 따라 장치 제어 |
| 위험 모드 | 위험 조건 감지 시 경고 및 일반 사용자 제어 제한 |

### 매뉴얼 모드

웹 GUI에서 조명, 부저, 커튼, 침대를 직접 조작합니다.

### 스마트 제어 모드

센서 데이터를 기준으로 장치 동작을 판단합니다. 조도에 따른 조명 제어 등 환경에 반응하는 자동 제어를 수행합니다.

### 루틴 모드

사용자가 실행 시간과 장치 동작을 등록합니다. 삭제하지 않은 루틴은 매일 같은 시간에 반복 실행해 일상적인 동작을 자동화합니다.

### 위험 모드

가스 감지 또는 온습도 센서 값이 설정한 위험 기준을 만족하면 자동으로 진입합니다. 위험 모드에서는 일반 사용자 제어를 제한하고 경고를 우선하며, 웹 화면에 발생 원인을 안내합니다.

## 웹 대시보드

- 센서 데이터 및 장치 상태 확인
- 제어 모드 선택
- 수동 장치 제어
- 루틴 등록 및 삭제
- 위험 경고 및 원인 표시
- 사용자 프로필 설정: 이름 및 사진
- 최근 활동 기록 확인

## 기술적 구현

### 임베디드 Linux 장치 제어

C 프로그램에서 Linux GPIO와 I2C를 활용해 센서와 액추에이터를 제어하고, UART로 보드 간 데이터를 전달합니다.

### 보드와 웹 서버 연결

웹 브리지에서 센서 데이터를 파싱하고 JSON으로 변환해 Flask API로 전송합니다. 웹에서 발생한 제어 명령은 시리얼을 통해 제어 보드에 전달합니다.

### 시간 기반 루틴 처리

백그라운드 스레드에서 현재 시간과 등록된 루틴을 확인합니다. 모터 구동 시간과 보드의 명령 처리 지연을 고려한 대기·재전송 로직을 구성했습니다.

## 실행 준비

1. 보드별 센서·액추에이터 배선과 GPIO 번호를 확인합니다.
2. 보드 간 UART 및 노트북과의 유선 네트워크를 연결합니다.
3. 코드의 서버 IP, 포트, 시리얼 장치 경로를 환경에 맞게 설정합니다.
4. 각 보드에서 센서·제어·웹 브리지 프로그램을 실행합니다.
5. 노트북에서 웹 서버를 실행합니다.

```bash
python3 -m pip install flask pyserial requests
cd code
python3 app.py
```

스마트폰이나 태블릿이 웹 서버에 접근할 수 있는 네트워크에 연결된 상태에서 대시보드에 접속합니다.
